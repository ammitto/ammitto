= Ruby API

== Purpose

This section documents the Ammitto Ruby API for programmatic access to sanctions data.

== Module Methods

The `Ammitto` module provides the main entry points:

=== Configuration

[source,ruby]
----
# Get current configuration
config = Ammitto.configuration

# Configure Ammitto
Ammitto.configure do |config|
  config.cache_dir = "~/.ammitto/cache"
  config.verbose = true
end

# Reset configuration
Ammitto.reset_configuration!
----

=== Search

[source,ruby]
----
# Basic search
results = Ammitto.search("Kim Jong")

# With options
results = Ammitto.search("Bank",
  sources: [:un, :eu, :us],
  entity_type: :organization,
  limit: 50,
  offset: 0
)

# Iterate results
results.each do |entity|
  puts "#{entity.display_name} (#{entity.entity_type})"
end
----

=== Cache Management

[source,ruby]
----
# Refresh cache
Ammitto.refresh_cache(sources: [:un, :eu])
Ammitto.refresh_cache(all: true, force: true)

# Check cache status
status = Ammitto.cache_status
# => { un: { cached: true, updated_at: "2026-02-26T00:00:00+00:00",
#            size: 7178346, age_seconds: 443 }, ... }
----

=== Available Sources

[source,ruby]
----
# List available source codes
sources = Ammitto.sources
# => [:au, :ca, :ch, :cn, :eu, :eu_vessels, :jp, :nz, :ru, :tr, :uk, :un,
#     :un_vessels, :us, :wb]
----

=== Data Repository

[source,ruby]
----
# Access the data repository
repo = Ammitto.data_repository(
  local_path: "./data",
  verbose: true
)

# Get statistics (parsed from api/v1/stats.json, so keys are strings)
stats = repo.stats
# => { "total_entities" => Integer, "total_entries" => Integer,
#      "sources" => { "un" => { "entities" => Integer, ... } }, ... }

# Query entities
entities = repo.query(name: "Smith", limit: 10)
----

== Core Classes

=== Search::QueryBuilder

Build complex search queries:

[source,ruby]
----
builder = Ammitto::Search::QueryBuilder.new("test",
  sources: [:un, :eu],
  limit: 100,
  offset: 0
)

query = builder.build
results = query.execute
----

=== Search::ResultSet

Work with search results:

[source,ruby]
----
results = Ammitto.search("test")

# Check if empty
results.empty?

# Get count
results.size

# Filter by entity type
persons = results.by_entity_type(:person)

# Filter by authority
un_results = results.by_authority(:un)

# Filter by status
active = results.by_status(:active)

# Get unique values
results.entity_types  # => [:person, :organization]
results.authorities   # => [:un, :eu, :us]

# Export
results.to_json_ld
results.to_json
----

== Entity Classes

All entities inherit from `Ammitto::Entity`, which is what `require "ammitto"`
loads and what `Ammitto.search` returns.

=== PersonEntity

[source,ruby]
----
entity = Ammitto::PersonEntity.new(
  id: 'un/KPi.066',
  entity_type: 'person',
  names: [{ full_name: 'KIM, Jong Un', is_primary: true }],
  birth_info: [{ year: 1984, country: 'KP' }],
  nationalities: ['KP']
)

# Attributes
entity.id              # => "un/KPi.066"
entity.entity_type     # => "person"
entity.display_name    # => "KIM, Jong Un"
entity.primary_name    # => NameVariant object
entity.all_names       # => ["KIM, Jong Un"]
entity.birth_date      # => Date object or nil
entity.birth_country   # => "KP"
entity.deceased?       # => false

# Methods
entity.matches?("jong un")  # => true
----

== Sanction Classes

=== SanctionEntry

[source,ruby]
----
entry = Ammitto::SanctionEntry.new(
  id: 'entry/un/KPi.066',
  entity_id: 'entity/un/KPi.066',
  authority: { id: 'un', name: 'United Nations', country_code: 'UN' },
  regime: { code: 'dprk', name: 'DPRK' },
  period: { listed_date: '2016-11-30' },
  effects: [{ effect_type: 'asset_freeze' }, { effect_type: 'travel_ban' }],
  status: 'active'
)

# Attributes
entry.id                  # => "entry/un/KPi.066"
entry.entity_id           # => "entity/un/KPi.066"
entry.authority           # => Authority object
entry.regime              # => SanctionRegime object
entry.status              # => "active" (see SanctionEntry::STATUSES)
entry.period.listed_date  # => #<Date: 2016-11-30>

# Status checks
entry.active?           # => true
entry.suspended?        # => false
entry.terminated?       # => false

# Methods
entry.authority_code    # => "un"
entry.effect_types      # => ["asset_freeze", "travel_ban"]
----

`period`, `effects`, and `reasons` are `nil` until set, so guard them
(`entry.period&.listed_date`) on entries built from partial data.
`Ammitto::SanctionEntry::STATUSES` lists the documented status values; the
model stores whatever string it is given, so it is a vocabulary, not a
constraint.

=== Authority

[source,ruby]
----
# Get authority by code
authority = Ammitto::Ontology.authority(:un)

authority.id            # => "un"
authority.name          # => "United Nations"
authority.url           # => "https://www.un.org/securitycouncil/sanctions/information"

# List all authorities
Ammitto::Ontology.authorities.keys
# => ["eu", "un", "us", "uk", "au", "ca", ...]
----

== Serialization

=== JSON-LD Serialization

[source,ruby]
----
serializer = Ammitto::Serialization::JsonLdSerializer.new

# Serialize entity
jsonld = serializer.serialize_entity(entity)

# Serialize entry
jsonld = serializer.serialize_entry(entry)

# Full document
doc = serializer.serialize_document(
  entities: [entity],
  entries: [entry]
)
----

=== Search Index Export

`require "ammitto"` does not autoload this exporter; require it explicitly.

[source,ruby]
----
require 'ammitto/serialization/search_index_exporter'

exporter = Ammitto::Serialization::SearchIndexExporter.new

# Both arguments are hashes (JSON-LD or model hashes), never model objects.
# The authority is read from a bare code, an `@id` IRI, or `countryCode` —
# any other shape lands in the index without an authority.
entities = [{ 'id' => 'un/KPi.066', 'entity_type' => 'person',
              'names' => [{ 'full_name' => 'KIM, Jong Un' }] }]
entries = { 'un/KPi.066' => { 'status' => 'active',
                              'authority' => { 'countryCode' => 'UN' } } }

# `add` dereferences the entry, so skip pairs with no entry
entities.each do |entity|
  entry = entries[entity['id']]
  next unless entry

  exporter.add(entity, entry)
end

# Export
exporter.export('./api/v1')
# Creates:
#   ./api/v1/search-index.json
#   ./api/v1/facets/authorities.json
#   ./api/v1/facets/types.json
#   ./api/v1/facets/countries.json
#   ./api/v1/facets/list_types.json
#   ./api/v1/facets/regimes.json
#   ./api/v1/facets/statuses.json
----

== Error Handling

[source,ruby]
----
begin
  results = Ammitto.search("test")
rescue Ammitto::SourceNotFoundError => e
  puts "Source not found: #{e.message}"
rescue Ammitto::NetworkError => e
  puts "Network error: #{e.message}"
rescue Ammitto::ParseError => e
  puts "Parse error: #{e.message}"
end
----
