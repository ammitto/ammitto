= Quick Start

== Purpose

This page helps you get started with Ammitto quickly, covering the most common use cases.

== Basic Usage

=== Search for Entities

The most common use case is searching for sanctioned entities:

[source,ruby]
----
require 'ammitto'

# Search across all sources
results = Ammitto.search("Kim Jong")
results.each do |entity|
  puts "#{entity.display_name} (#{entity.entity_type})"
end
----

=== Filter by Source

[source,ruby]
----
# Search only UN and EU lists
results = Ammitto.search("Putin", sources: [:un, :eu])
----

=== Filter by Entity Type

[source,ruby]
----
# Entity type is not a search option — search reads only sources, limit
# and offset. Filter the result set it returns.
results = Ammitto.search("Bank")
organizations = results.by_entity_type(:organization)
----

== CLI Quick Start

=== Search from Command Line

[source,bash]
----
# Basic search
ammitto search "Kim Jong"

# Search with filters
ammitto search "Bank" --type organization --source eu

# Output as JSON
ammitto search "Smith" --format json
----

=== Get Entity Details

[source,bash]
----
# Get by reference
ammitto get un/KPi.066

# Get with full JSON-LD output
ammitto get un/KPi.066 --format json
----

=== Fetch Latest Data

[source,bash]
----
# Fetch from a specific source
ammitto fetch eu --output-dir ./data

# Fetch from all automatable sources (skips manually managed cn and jp)
ammitto fetch --all
----

== Data Access

=== Load from Data Repository

These calls read a local harmonized data repository. `query` and `get` raise
`Ammitto::NotFoundError` until `api/v1/all.jsonld` exists — clone `ammitto/data`
or run `ammitto harmonize --all --combine` first.

[source,ruby]
----
# Access the data repository
repo = Ammitto.data_repository

# Get statistics (parsed JSON, so keys are strings)
stats = repo.stats
puts "Total entities: #{stats['total_entities']}"

# Query entities — returns an Array of JSON-LD hashes
entities = repo.query(name: "Smith", limit: 10)
----

=== Access Individual Entity

`Repository#get` returns the raw JSON-LD hash, not an entity object — or `nil`
when no entity matches the id.

[source,ruby]
----
# Get entity by ID
entity = Ammitto.data_repository.get("un/KPi.066")

puts entity['names'].first['full_name']
puts entity['entity_type']

# Build a model from it when you want the entity API
model = Ammitto::PersonEntity.new(entity)
puts model.display_name
----

== Working with JSON-LD

=== Export to JSON-LD

The serializer takes an entity model, not a repository hash — pass the `model`
built above, not the raw `entity`.

[source,ruby]
----
# Serialize an entity
model = Ammitto::PersonEntity.new(
  id: 'un/KPi.066',
  entity_type: 'person',
  names: [{ full_name: 'KIM, Jong Un', is_primary: true }]
)

serializer = Ammitto::Serialization::JsonLdSerializer.new
jsonld = serializer.serialize_entity(model)
puts jsonld.to_json
----

=== Export to RDF Formats

[source,bash]
----
# Export all data to JSON-LD (--combine adds the merged all.jsonld/all.ttl)
ammitto harmonize --all --combine --output-dir ./api/v1

# Creates:
# ./api/v1/sources/un.jsonld
# ./api/v1/sources/eu.jsonld
# ./api/v1/all.jsonld   (with --combine)
# ./api/v1/all.ttl      (with --combine, Turtle format)
----

== Using the Search Index

The lightweight search index (~8MB) enables fast client-side search. The gem
builds and exports the index; loading and querying it is the client's job.

[source,ruby]
----
require 'ammitto/serialization/search_index_exporter'

exporter = Ammitto::Serialization::SearchIndexExporter.new

# Both arguments are hashes, never model objects. The authority is read from
# a bare code, an `@id` IRI, or `countryCode`.
entity_hash = { 'id' => 'un/KPi.066', 'entity_type' => 'person',
                'names' => [{ 'full_name' => 'KIM, Jong Un' }] }
entry_hash = { 'status' => 'active',
               'authority' => { 'countryCode' => 'UN' } }
exporter.add(entity_hash, entry_hash)

# Write search-index.json plus the facet files
exporter.export('./api/v1')
----

Read the exported index back with any JSON parser:

[source,ruby]
----
index = JSON.parse(File.read('./api/v1/search-index.json'))
results = index['entities'].select do |e|
  e['primaryName'].to_s.downcase.include?('kim')
end
----

== Common Patterns

=== Compliance Screening

[source,ruby]
----
# Screen a customer name
def screen_customer(name)
  results = Ammitto.search(name, limit: 5)
  if results.any?
    puts "Potential matches found:"
    results.each do |r|
      puts "  - #{r.display_name} (#{r.entity_type})"
    end
  else
    puts "No matches found"
  end
end
----

=== Batch Processing

[source,ruby]
----
# Process multiple names
names = ["John Smith", "Jane Doe", "Acme Corp"]
names.each do |name|
  results = Ammitto.search(name)
  puts "#{name}: #{results.size} matches"
end
----

=== Export to File

[source,ruby]
----
# Export search results to JSON
results = Ammitto.search("test")
File.write('results.json', results.to_json)
----
