= Changelog

All notable changes to the `ammitto` gem are recorded here, newest first.
Each line names the pull request on https://github.com/ammitto/ammitto[ammitto/ammitto] that made the change.

== 2.0.0 (unreleased)

=== Breaking changes

* Ruby 3.3 or later is required; 1.0.0 accepted Ruby 2.7. (#12, #18)
* `lutaml-model` is pinned to `~> 0.8.29` (1.0.0 allowed `~> 0.7`), and the EU and US XML models use `Lutaml::Xml::Namespace` classes. (#12, #128)
* `harmonize` writes `all.jsonld` and `all.ttl` only when passed `--combine`; 1.0.0 always wrote them. (#12)
* `ammitto fetch --force` and the global `--log-level` option, which 1.0.0 never honoured, are removed. (#12)
* `harmonize` serializes JSON-LD through `JsonLdSerializer` with camelCase keys, `@id` and `@type`, matching the published context. (#12)
* The search index is sharded by authority: `search-index/<code>.json` plus `search-index/manifest.json` replace the single `search-index.json`. (#119)
* Search index rows replace the single `birthYear` string with one `birthYears` array of typed year and date range values, each with its own `circa`. (#111, #117)
* Published birth data no longer invents dates: a bare year stays a year, a date is set only when the source states day, month and year, a missing month gives no date, year spans are published as `yearRangeFrom` and `yearRangeTo`, and full date spans as `dateRangeFrom` and `dateRangeTo`. (#44, #50, #53, #103)
* A local id longer than 64 characters that collides with another id in its scope after the cut now ends in the first 8 hex characters of a SHA-256 digest; ids that do not collide keep their plain cut. (#163)
* CN parties whose cut names clash within one announcement get ids from their full names, numbered when they still clash. (#165)
* CN notices are filed under the list of the directory they sit in, and export-control notices take list-qualified announcement and group ids such as `group/cn/import-export-control-list-202513`. (#178)
* `harmonize` health gates are strict for every source by default; a workflow names its own exemptions with `--allow-empty`, which replaces the hardcoded dormant source list. (#19)
* `ammitto search` exits 1 and writes to stderr when it cannot reach the data, and `ammitto export` raises `Ammitto::CacheError` on an unreadable cache instead of writing an empty file. (#72)
* `fetch` refuses a harvest that wrote no records or collapsed against the previous one, `fetch jp` and `fetch ru` exit nonzero, and `fetch --all` skips cn, ru and jp. (#26, #39, #40, #74, #81)
* CN and vessel entries are filed under their real list instead of `entry/<code>/unknown/`, which changes their entry IRIs, and the vessel registry keys are `eu_vessels` and `un_vessels` (hyphen aliases still resolve). (#27)
* `Extractors::Registry` treats only an absent extractor file as no extractor; a `LoadError` from an extractor's own requires now propagates, and `fetch` fails just that source. (#155)
* `UsExtractor::SDN_ZIP_URL` and `CONSOLIDATED_ZIP_URL` are removed and `LEGACY_SDN_URL` is renamed `SDN_URL`. (#89)
* A record with no usable identifier, a document type id that cannot become a safe path, and a CN announcement or modification whose id cannot name it are refused instead of published under a shared or fallback id. (#62, #77, #158)
* `require 'ammitto/errors/base_error'` is now `require 'ammitto/error'`. (#149)
* The gem packages only runtime files: `lib/`, `exe/`, `schemas/`, the gemspec, `README.adoc`, `LICENSE.txt` and this changelog. (#179)
* An untyped legacy RU party raises `Ammitto::ParseError` instead of being published as a person. (#186)
* `Exporter::SimpleExporter` and `Exporter::JsonLdExport`, deprecated in favour of the `harmonize` and `export` commands, are removed. (#161, #192)

=== Added

* `Ammitto::Validation`, one entry point for file and object validation (`Validation.file`, `Validation.object`). (#23)
* `ResultSet#skipped_sources` and `ResultSet#complete?`, so a search names the sources it could not read; unknown source codes are reported as skipped. (#71, #137)
* `ResultSet#term` carries the search term, and `Entity#authority` is derived from the entity IRI so `ResultSet#authorities` and `#by_authority` work on search results. (#166)
* `Ammitto::SourceDataNotFoundError`, a `NetworkError` raised when the API answers 404 for a source. (#162)
* `harmonize` writes per-source `sources/<code>.jsonld` aggregates and `context.jsonld`. (#12)
* `fetch --allow-shrink` accepts a harvest the collapse guard would refuse. (#81)
* `ammitto validate` and `ammitto source` commands. (#16)
* A `parse_failure_mode` setting (`AMMITTO_PARSE_FAILURE_MODE`: `warn`, `silent` or `raise`) for unreadable source dates, raising `Ammitto::ParseFailureError` in `raise` mode. (#120)
* `harmonize --report PATH` writes the outcome as JSON. (#60)
* `fetch --prune` deletes record files the source no longer lists, including for sources with no filename prefix. (#151, #172)
* `api/v1/index.jsonld` catalogues the artefacts a run produced. (#56)
* Per-source Turtle, `sources/<code>.ttl`, alongside the JSON-LD aggregate. (#121)
* Organization and document type page summaries. (#49)
* `SanctionPeriodModification` models a CN measure modification, with target ids, `targetAnnouncementDocumentId` and an embedded announcement. (#170)
* `SanctionEntry#modifications` and `#status_as_of(date)`, and `harmonize` applies CN measure modifications to their target announcement's entries as status history. (#170, #180)
* A reader for data-ru's announcement documents. (#83)
* EU vessel designations carry the regime and measure the DMA states. (#143)
* A fleet health monitor for the data repository fetch schedules. (#45)
* Homepage, source, changelog and bug tracker URIs in the gemspec metadata. (#139)

=== Fixed

* The default API base URL is `https://www.ammitto.org/api/v1`; the 1.0.0 default answered 404. (#12, #67)
* `status` and `export` read the flat `cache/sources/<code>.jsonld` cache that `Ammitto.search` writes. (#12)
* EU ids no longer collapse to one URI, CH records keep their names, AU vessels are published as vessels, and `Ammitto.sources` lists every source. (#12)
* An RU announcement party whose type is missing or unknown is refused with `Ammitto::ParseError` instead of published as a person. (#150)
* `Ammitto.search`, `refresh_cache` and `cache_status` raised `NameError` in 1.0.0; the Ruby API examples in the docs now run. (#12, #34)
* A search survives a source it cannot reach, skips a source whose download fails, and reads the per-source files when the combined aggregate is absent. (#42, #68, #70)
* Source caches are written atomically and a corrupt cached source is skipped. (#140)
* Harmonize no longer loses entities silently, crashes on bad input, or reads stale processed directories; YAML parse failures are reported per file. (#25, #27, #28)
* Fetch failures are reported instead of swallowed, and the fetch workflow invocation works for `all` and comma separated inputs. (#26, #39)
* Turkey: records without a reference get a stable identity, and a designee is no longer lost nor four columns collapsed. (#31, #33)
* Authority nodes are keyed on their id, entity entry links, group ids and legal citations are serialized, and regime IRIs are sanitized so the published RDF parses. (#35, #36, #59)
* Entries carry the regime name on their reference, and an organization is matched on its identifier rather than a prefix of it. (#58, #61)
* Every source's supplement directories are loaded, and oversized legal instrument slugs are clamped to the filename limit. (#24, #54)
* AU citizenships split on DFAT's `;` separator, AU dates no longer carry a month or day the source did not state, AU numeric birth dates and ISO control dates are read as published, and unreadable AU, NZ and EU vessels dates are reported. (#37, #108, #152, #154)
* `ammitto validate china` accepts the data-cn corpus as written: announcements accept the `cn/...` list ids, legal instruments accept `authority` and `publisher`, and `supporting/sanction-lists.yml` is checked against its own registry schema. (#184)
* Search index rows are deduplicated by entity id, and harmonize applies per-source quality gates. (#27)
* Turkey records carry their nationality, and `fetch` refuses filenames that collide across sources before writing anything. (#33)
* Source dates that cannot be parsed are reported instead of dropped, an unreadable supplement file is reported without `VERBOSE`, and fetch time parse failures are counted in the fetch summary. (#120, #147, #153)
* An unreadable expiry leaves the indefinite flag unknown instead of false. (#148)
* Birth data: the circa marker is read consistently and set on UK and RU dates, every candidate birth year is published, every birth claim reaches the search row, and AU no longer reads a birth year out of the middle of a date with a missing separator (`10/061962`). (#106, #109, #110, #111, #118, #138)
* CH is dispatched by record shape, CA `EntityOrShip` is mapped, and JP announcements are ingested. (#38)
* Canada is read by the element names it publishes. (#80)
* The un_vessels fetch reads the live UN 1718 PDF and refuses a redirect to http. (#41, #43)
* The Japan source command reaches its extractor, and a blocked RU fetch or a CN scrape that could not read the site is refused loudly. (#39, #73, #79)
* Turkish entity predicates and mixed set `ResultSet` type filters. (#46)
* Downloaded workbooks open in binary mode. (#88)
* A blank CN instrument id, or a document id the sanitizer cannot use, is treated as absent. (#91, #92)
* The YAML and JSON adapters are forced to the standard ones to avoid a yeptris FFI heap corruption bug, and an invalid `:datetime` model type is fixed. (#129, #130)
* `Wb::Response` reads and writes WB firms through lutaml's `ZPROCSUPP` custom methods, which built no firms and raised on `to_json`. (#159)
* Ontology defects: missing presence helpers, `Types.normalize_effect_type` and `normalize_instrument_type`, a private `BirthInfo#to_hash`, `add_status_change` not recording transitions, and missing sanction effect types. (#21)
* `Ammitto::Error` overrides accept `Exception#full_message` keywords. (#133)
* A source whose extractor file is broken fails instead of reading as having no fetch path. (#155)
* The collapse guard ignores another source's `_index.yaml`. (#167)
* A force reclone refuses a directory that is not a clone of the remote, and a local file URL is cloned from its path, as Git for Windows needs. (#141, #146)
* A CN modification's announcement title and document id are read as data-cn writes them. (#164)
* Each search index shard holds a row once. (#182)
* `--prune` never deletes a recorded file that is no longer a regular file. (#183)
* `--verbose` reaches `ammitto validate` and `ammitto source`. (#185)
* An AU row of an unknown Type is kept and published as an organization so it validates. (#171, #189)

=== Changed

* Sources, exporters and the ontology were updated, adding a Neo4j exporter and an entity resolution service. (#16)
* Every gem error is rescuable as `Ammitto::Error`. (#144)
* `Ammitto::Configuration` honours the documented `AMMITTO_*` environment variables, with precedence: `Ammitto.configure` or a CLI flag, then the environment, then the default; downloads use the configured timeouts. (#145)
* `ammitto process` exits with a message pointing to `harmonize`. (#12)
* Verbose output goes through `Ammitto.configuration`. (#160)
* CN sanctions are marked indefinite, since the list publishes no expiry. (#136)
* `effectiveDate` is typed `xsd:date` in the JSON-LD context. (#176)
* Two different regimes that cut to one slug raise `Ammitto::Error` instead of merging. (#187)
* A legal instrument supplement file with no id logs a warning. (#188)
* The EU vessels workbook link is discovered from the DMA index page. (#142)
* The CH list is fetched live instead of from a local snapshot. (#190)
* The source extractors that used `URI.open` now download through one shared HTTPS client, `Extractors::HttpClient`. (#47, #113)
* The knowledge graph loader mints its IRIs through the harmonize collision registry. (#173, #175)
* RU fetch refusals raise typed errors (`Ammitto::NetworkError`, `Ammitto::ParseError`, `Ammitto::Error`) instead of bare `RuntimeError`, matching CN. (#78)
* The executable syncs stdout so failure lines follow their detail in CI logs. (#131)
* Documentation describes the CLI that exists, the sharded search index and the current data flow, with dead links fixed. (#17, #29, #30, #93, #177)
* Internal refactors with no behaviour change: one class per file across the source models and split commands, shared spec helpers, lint and CI cleanups, and fleet monitor fixes. (#11, #20, #22, #32, #48, #63, #64, #66, #69, #76, #84, #85, #87, #90, #95, #96, #97, #98, #99, #100, #102, #104, #105, #112, #114, #115, #116, #122, #123, #124, #125, #126, #127, #132, #134, #135, #156, #157, #168, #169, #174, #191)

=== Removed

* The OFAC `SDN_ADVANCED.ZIP` fallback, which never yielded a record. (#89)
* The unreachable Canada parser methods and the EU `ProcessedEntity` models. (#82, #101)

== 1.0.0 (2026-02-26)

* First release of the rewritten gem: a unified JSON-LD model for persons, organizations, vessels and aircraft from 15 sources, the `Ammitto.search` client with a local cache, and the `fetch`, `harmonize` and `export` commands.
