= TODO task board

Task files for the finalization plan (phases 1-4 + deferred). Convention:
one PR completes a task AND deletes its file in the same change, so
`ls TODO.phase-*` is the live status and the git log of deletions is the
completion history. Sources: the gap matrix, defect catalog, work sizing,
fetch diagnosis, and fork briefs of 2026-07-28 (local .codex-context).
Tasks marked USER need a maintainer action/ruling, not code.
